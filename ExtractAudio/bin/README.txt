Положите сюда ffmpeg.exe (и желательно ffprobe.exe).

Проще всего: запустите install.cmd — он скачает их автоматически.
Либо вручную: setup-ffmpeg.ps1 (правый клик -> Run with PowerShell).

Ручная загрузка: https://www.gyan.dev/ffmpeg/builds/  (ffmpeg-release-essentials.zip)
Из архива нужны два файла из папки bin\:  ffmpeg.exe  и  ffprobe.exe
