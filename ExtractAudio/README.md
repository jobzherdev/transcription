# Извлечь аудио → mp3 для распознавания речи

Утилита для Windows 10/11. Один правый клик по видео → рядом появляется `.mp3`,
оптимизированный под STT (Whisper, GPT-4o transcribe, Yandex SpeechKit):
**mono · 16 000 Hz · 48 kbps**. Без терминала, без настроек, без admin-прав.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `main.ps1` | Логика: прогресс-окно (WPF) + ffmpeg + защита `INCOMPLETE_` |
| `silent-wrapper.vbs` | Скрытый запуск (без вспышки CMD-окна) |
| `install.cmd` / `install.ps1` | Регистрация пункта меню в `HKCU` (без UAC) |
| `uninstall.cmd` / `uninstall.ps1` | Удаление пункта меню |
| `setup-ffmpeg.ps1` | Авто-загрузка `ffmpeg.exe` + `ffprobe.exe` в `bin\` |
| `bin\` | Сюда кладётся `ffmpeg.exe` (скачивается автоматически) |
| `логи\` | Лог-файл (создаётся при первом запуске) |

## Установка (3 шага)

1. Скопируйте всю папку `ExtractAudio` в постоянное место
   (например `C:\Tools\ExtractAudio`). **Не перемещайте её после установки** —
   пути в реестре абсолютные.
2. Дважды кликните `install.cmd`. Он сам скачает ffmpeg (~96 MB) и
   зарегистрирует пункт меню. Прав администратора не нужно.
3. Правый клик по любому `.mp4 / .mkv / .mov / .webm / .avi / .m4v / .flv /
   .ts / .wmv / .mpg / .mpeg` → **«Извлечь аудио»**.

> Если Windows ругается на запуск `.ps1` — `install.cmd` уже запускает их с
> `-ExecutionPolicy Bypass`, поэтому менять политику системы не требуется.

## Проверка

- Кликните «Извлечь аудио» — по центру экрана появится тёмное полупрозрачное
  окно с прогрессом (фокус у вас не отбирается). По завершении оно исчезает само,
  рядом с видео лежит `<имя>.mp3`.
- Во время конвертации файл называется `INCOMPLETE_<имя>.mp3`; при успехе
  переименовывается в `<имя>.mp3`. Если файл остался с префиксом `INCOMPLETE_` —
  значит процесс был прерван, и его **нельзя** отдавать в STT.
- Проверить параметры результата:
  `bin\ffprobe.exe -v error -show_entries stream=channels,sample_rate,bit_rate -of default=nw=1 "имя.mp3"`
  → должно быть `channels=1`, `sample_rate=16000`, `bit_rate≈48000`.

## Удаление

Дважды кликните `uninstall.cmd` — пункт меню исчезнет. Сами файлы утилиты
останутся; удалите папку вручную, если она больше не нужна.

## Если что-то не работает

Не присылайте скриншот — пришлите содержимое лог-файла
`логи\extract-audio.log`. Там фиксируются все запуски, ошибки и причина
(строка ffmpeg stderr) в формате
`[дата время] вход -> выход | длительность | статус`.
